# Face Detection using Python & OpenCV

## 📌 Project Overview

Face Detection is a real-time computer vision project developed using Python and OpenCV. The application captures live video through a webcam and detects human faces using the Haar Cascade Classifier. Once a face is detected, the system highlights it with a bounding box in real time.

This project provides practical experience with image processing, webcam integration, grayscale conversion, object detection, and real-time computer vision.

## 🎯 Objectives

- Detect human faces from a live webcam feed.
- Process video frames using OpenCV.
- Convert captured frames into grayscale images.
- Apply the Haar Cascade Classifier for face detection.
- Display detected faces using bounding boxes.
- Understand the fundamentals of real-time computer vision.

## 🛠️ Technologies Used

- Python 3.11
- OpenCV
- Haar Cascade Classifier
- Computer Vision
- Webcam
- VS Code
